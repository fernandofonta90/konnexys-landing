# Konnexys — Brand

Símbolo "Encaje": dos cuadrados redondeados desplazados en diagonal,
unidos en la esquina compartida con un tercer tono.

## Archivos
- logo-mark.svg             Símbolo a color (header, pie, mini-íconos, favicon)
- logo-mark-mono-white.svg  Símbolo monocromo blanco (fondos oscuros)
- favicon.ico               16/32/48, derivado de logo-mark.svg (se sirve desde la raíz)
- icon-180.png / icon-512.png   Ícono de app sobre fondo crema #F7F4EE (copiados a assets/)

## Paleta
- durazno #FC954C · naranja #FB5C1C (marca) · encaje #B23F13 · tinta #3a2c22 · crema #F7F4EE

## Wordmark
"konnexys" en minúscula, Hanken Grotesk 800, color tinta #3a2c22.
Fuente alojada en el sitio (assets/fonts/HankenGrotesk-latin.woff2), solo peso 800. No usar Google Fonts.

## Uso
- Header: símbolo a color + wordmark tinta. El logo enlaza a /.
- Pie (arena): símbolo a color + wordmark tinta #3a2c22 (no la versión blanca).
- Fondos oscuros: logo-mark-mono-white.svg.
- Favicon: favicon.ico en la raíz + logo-mark.svg (reemplaza el SVG embebido).
- Datos estructurados: campo logo → assets/icon-512.png.
- No tocar og.jpg.
